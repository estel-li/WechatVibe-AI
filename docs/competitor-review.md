[Chatlog 官方仓库](https://github.com/sjzar/chatlog)和[PyWxDump 官方仓库](https://github.com/xaoyaoo/PyWxDump)目前保留的是 2025-10-20 的项目移除通知，不再提供代码与维护，不能把旧功能清单当作仍可用的竞品能力。

MemoTrace 的 `LC044/MemoTrace` 地址本次返回 404。维护者的[WeChatMsg 留痕仓库](https://github.com/LC044/WeChatMsg)仍可访问，其当前说明明确不会继续更新，并保留个人/双人 2024 年度报告入口与 [AnnualReport 源码](https://github.com/LC044/AnnualReport)链接。可参考历史回顾的产品形式；本次不将其列为正在维护的聊天客户端，也不依赖转载包或旧分支。

## 已有能力，不重复建设

知意 AI 已有完整历史的分段总结、全面/决定/时间线/情绪/待办/群聊/速览 7 种总结预设、6 种关系提示词、自定义 API 与本地模型分析、会话筛选、统计和人物画像。长记录按完整来源片段处理，并校验覆盖，没有为了“新功能”再搭建另一套摘要流程。

## 本次实际借鉴和交付

| 改进 | 完整使用流程 | 成本与隐私边界 |
| --- | --- | --- |
| 回复语气选择 | 选关系 → 选简洁直接、温暖真诚、正式清晰、轻松幽默、礼貌有边界或原关系提示 → 填本次想表达的意思 → 生成 → 复制或放入草稿 | 切换语气本身不会调用模型；不改用户保存的关系提示；本次表达要求优先；一轮只生成一条草稿 |
| Markdown / TXT 本地导出 | 总结或回复生成完成 → 点击导出 → Windows 原生保存对话框选择位置；浏览器环境下载文件 | 直接导出当前结果，不再调用 AI；保留中文文件名，移除非法字符；Markdown 将模型文本放入安全代码围栏；不写入 API 配置、账户 ID 或完整历史 |
| 结果范围与用量 | 结果旁显示原生成模型、所选范围、来源片段覆盖、模型调用次数与已报告 token | 服务未返回 usage 时明确显示未报告；不虚构费用；只透传有效数值，不透传供应商原始字段或密钥 |
| 分页结果保留 | 对话总结与回复草稿分别保留；切标签无需重新生成；切会话/账号立即清空两类结果 | 只保留当前进程、当前会话的结果；不写浏览器持久存储；旧任务取消和异步返回不得覆盖新会话 |
| 生成时的渲染优化 | 每秒获取进度；结果文本没有变化时保留现有 DOM 和选区 | 轮询由约 86 次/分钟降至约 60 次/分钟；不因此增加模型请求或重复付费生成 |

## 延后功能与原因

| 候选功能 | 延后原因 / 后续前提 |
| --- | --- |
| 年度/双人回顾、关系纪念册 | 应基于完整统计、明确时间边界及可验证数据先建设稳定报告模型；本次已提供时间线总结与可保存结果，避免把有限 AI 样本包装成完整年度统计 |
| 本地语义检索、长期记忆 | 需要新增索引、账号隔离、增量更新、删除与迁移策略，还会增加分发体积；现有关键词定位和完整范围读取继续可用 |
| 定时摘要、关键词通知、自动回复 | 需要后台生命周期、去重、频率、收费预算、通知授权与明确发送边界；当前一切 AI 生成和导出均由用户点击 |
| 语音/图片理解与全媒体导出 | 当前桥只保证文本和媒体类型，尚未保证媒体解密、格式转换和模型输入；不通过生成提示词猜测未读取的媒体 |
| MCP / 移动端局域网访问 | 需要单独设计调用方认证、最小权限、数据脱敏和网络公开面；本机服务继续保持当前作用域 |
