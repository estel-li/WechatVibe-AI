# 知意 AI / WechatVibe AI 品牌资产

产品中文名称为“知意 AI”，英文名称为“WechatVibe AI”。2026-10-07，维护者提供并选定新的正式 logo：深绿色圆角底、两枚浅色对话气泡，中央负空间形成四芒星，表达对话与 AI 理解。

此前六个候选图及完整生成提示词保存于 [icon-options](icon-options/prompts.json)，旧版采用的 [⑤青金罗盘](icon-options/05-teal-compass.png) 保留为历史记录。
