# 知意 AI / WechatVibe AI 1.2.2

通用设置新增“界面配色”，可将当前柔和风格切换为标准灰白与微信绿。配色独立于深浅主题，选择后立即生效并自动保存，重启后继续使用。

- **柔和配色**：保留现有深色灰绿、浅色蓝灰风格。旧配置及首次使用默认采用柔和配色。
- **标准配色**：使用中性背景和微信绿，统一聊天气泡、按钮、设置、人物画像、AI 对话助手与标题栏。
- 支持柔和深色、柔和浅色、标准深色、标准浅色四种组合，原生窗口背景同步切换。
- 配色切换保留缩放、模型、API Key 和聊天数据；1.2.1 的统一模型配置及提示词预设继续可用。
