# 知意 AI / WechatVibe AI 1.2.1

AI 模型改为统一在“设置 → 通用设置”配置，意图识别、人物画像、对话总结和帮我回复共用同一个已保存的 API 地址、模型、Key 与上下文容量。

- 新增 DeepSeek、MiniMax、智谱 Zhipu、Kimi、硅基流动和自定义 API 服务预设，支持获取模型、手动输入模型 ID、测试连接和保存。
- 新配置默认 1,000,000（1M）tokens 上下文；已有的明确容量保留，较小容量模型可按实际支持范围调整。
- AI 对话助手移除“模型与提示词”设置页，只保留“对话总结”和“帮我回复”。两页各有提示词下拉框与编辑框：7 条总结预设、6 条回复预设，可分别编辑保存。
- 更换 API 模型、容量或清除 Key 会停止助手旧任务并清除过期结果。切回本地 Laya 进行意图和画像分析时，总结与回复仍使用保存的 API 模型。
- 旧版只配置过助手时，自动迁移其加密配置；若已有通用 API 配置，以通用配置为准。迁移不会自动启用消息分析，原助手配置留作备份。
- 项目主页、关于页、问题反馈与更新检查改为 [estel-li/WechatVibe-AI](https://github.com/estel-li/WechatVibe-AI)。

## 升级与验证

仓库改名后，1.2.0 及更早版本的更新器无法跟随旧 GitHub API 地址的重定向。这次请从本页手动下载安装版或绿色版升级；1.2.1 已使用新仓库地址，后续可继续在软件内检查更新。

升级前退出应用，保留原有 `client/.local` 和 `client/.models`。覆盖程序文件时不覆盖这些目录。API Key 继续通过 Windows DPAPI 加密保存，用户聊天数据、Key 和模型权重均不进入发行包。

完整回归与两个发行包的原生验证记录见 [1.2.1 发行验证](../verification/release-1.2.1.json)。原生验证使用虚构对话和本机合成模型接口，覆盖全量 1305 条消息、截断恢复、时间范围、分别保存提示词、共用模型配置、意图与画像、缓存切换、小窗口、剪贴板、取消任务与会话切换。本轮未连接真实微信账号或外部付费模型。
