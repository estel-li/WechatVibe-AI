# 知意 AI / WechatVibe AI v1.1.0

本版加入 AI 聊天总结与回复辅助，修复消息较多时内部整理输出被截断的问题，更新双语名称和青金罗盘图标，由 [estel-li](https://github.com/estel-li) 维护。

## 下载与启动

| 文件 | 使用方式 |
| --- | --- |
| `WechatVibe-tauri2-1.1.0-windows-x64-setup.exe` | 安装版，按向导安装到当前用户目录 |
| `WechatVibe-tauri2-1.1.0-windows-x64.zip` | 绿色版，解压后保留完整 `tauri2-portable` 目录，启动 `WechatVibe.exe` |

需要 Windows 10/11 x64、WebView2 Runtime 和已登录的 Windows 微信 4.x。安装器在 WebView2 缺失时提供安装引导；绿色版需要系统已有该运行时。两个包都内置 Node/Python，不包含 Laya 模型权重；使用本地分析时在设置中下载或选择模型，使用 API 时无需下载模型。

## 本版本内容

- **AI 聊天总结**：处理当前会话的全部历史或指定时间，包含尚未滚动加载的记录，整理主题、安排和待办。
- **帮我回复**：根据聊天上下文和普通朋友、亲密朋友、同事、亲戚、长辈或自定义关系生成草稿，支持附加要求、重新生成、复制和放入草稿。
- **长聊天修复**：内部笔记采用明确的压缩目标和更大的输出预算，截断时使用完整原片段重新整理一次，完成后才合并；重复截断会明确报错。
- **DeepSeek 1M 上下文**：新官方配置默认 1,000,000 tokens；旧配置保留已有数值，已识别的官方模型可点击“使用1M上下文”并保存。
- **时间快捷选择**：总结与回复增加最近1天、最近一周、最近一月，支持秒级时间及月末日期调整。
- **独立助手配置**：获取模型、测试连接、编辑和保存总结及关系提示词；API Key 使用 Windows DPAPI 加密保存。
- **双语品牌**：名称为“知意 AI / WechatVibe AI”，采用青金罗盘图标；首页图片更新为实际 Tauri 界面与虚拟数据，展示总结、回复和模型配置。

总结与回复由用户主动发起，回复结果由用户检查后自行使用。原有消息情绪、意图、人物与群聊画像、本地模型、API 和账号缓存继续提供。

## 从 1.0.0 升级

可在“设置 → 关于 → 当前版本”检查更新。发布页附带独立 Ed25519 签名的 `update-manifest-tauri2.json`、签名和校验文件，供应用内更新使用。手动安装只需下载 EXE 或 ZIP，`SHA256SUMS.txt` 可核对全部发布资产。

手动覆盖升级前完全退出应用，使用完整运行包，并保留原安装中的 `client/.local`（账号、配置及缓存）和 `client/.models`（已有模型）。便携版目录需要可写。安装到新目录时，新目录不会自动复制旧目录的账号数据；保留原目录后再决定迁移方式。

新包不包含聊天数据、账号配置、API Key 或模型权重。此轮发布验证使用合成聊天和本地模型接口，覆盖完整回归、两种包的运行与 AI 操作；未连接真实微信账号。此前真实 DeepSeek 合成对话验证与长聊天修复记录见 [AI 助手说明](../../docs/ai-assistant.md)。启用 API 后，会将任务所需的聊天片段发送至用户配置的服务。

发布检查通过 487 项 Node、495 项 Python、4 项 Rust 测试及 8 个脚本套件；绿色版和安装包内的应用分别通过 20 项原生桌面检查，包内容与签名均已校验。文件大小、SHA-256 和测试记录见 [1.1.0 发行验证](https://github.com/estel-li/WechatVibe-AI/blob/v1.1.0/docs/verification/release-1.1.0.json)。
