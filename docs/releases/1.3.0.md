# 知意 AI / WechatVibe AI 1.3.0 升级清单

发布日期：2026-10-08（香港时间）。此版围绕日常查找、回复与复盘效率，以及生产运行的异常处理进行改进。

| 改进 | 使用方式与效果 |
| --- | --- |
| 未读筛选 | 会话列表切换全部 / 未读，快速聚焦需要处理的对话；未读是本工具按最近查看位置计算的提示。 |
| 键盘导航 | 在会话列表使用方向键、Home / End、Enter；界面提供快捷键说明，支持快速搜索。 |
| 返回最新 | 查看较早消息时显示返回最新入口，快速回到当前对话尾部。 |
| 小窗口与缩放 | 720×520 窗口、150% 缩放下复制及 AI 操作仍可达，调整布局保留消息阅读区。 |
| 历史搜索 | 命中词高亮，翻回已查看页直接使用内存缓存；请求失败后保留重试入口。缓存随账号、会话和查询切换失效。 |
| 回复语气 | 按关系提示词生成的基础上，可选简洁直接、温暖真诚、正式清晰、轻松幽默、礼貌有边界。 |
| 结果保留 | 同一会话中切换总结 / 回复后恢复各自完成的结果，减少误操作和重复付费生成。 |
| 覆盖与用量 | 显示生成所用模型、消息数量、时间覆盖与服务商返回的 token 用量；缺失用量保持未知。 |
| 本地导出 | 完成的总结或回复可导出 Markdown / TXT。Windows 原生保存对话框选择位置，取消可正常返回；保留中文文件名。 |
| 刷新效率 | 减少重复读取本地存储、历史搜索请求、助手轮询和相同结果重绘。 |
| HTTP 稳定性 | Windows 过大请求能收到错误，补全长度冲突、传输格式、不完整请求和超时边界处理；错误不回显内部路径。 |
| 异常恢复 | 清除账号前的预备步骤失败时恢复服务；畸形分析进程响应不再打断后续正常响应。 |
| 读取稳定性 | 限制异常压缩消息展开量，隔离会话去重，重复行仍继续分页；并发快照使用独立临时文件。 |
| 模型响应边界 | 普通响应上限 2 MiB，SSE / NDJSON 流量上限 16 MiB；保持增量输出，超限取消上游，不因超限追加付费兼容请求。 |
| 发布质量 | 源码、锁文件、桌面版本、README 下载链接与发布说明自动核对，Windows CI 运行完整回归、Rust 检查和生产依赖审计。 |

## 下载与升级

- [Windows x64 安装版](https://github.com/estel-li/WechatVibe-AI/releases/download/v1.3.0/WechatVibe-tauri2-1.3.0-windows-x64-setup.exe)
- [Windows x64 绿色版](https://github.com/estel-li/WechatVibe-AI/releases/download/v1.3.0/WechatVibe-tauri2-1.3.0-windows-x64.zip)

绿色版完整解压后启动 `WechatVibe.exe`。两个包均带 Node / Python 运行环境，标准包不含 Laya 模型权重，可从应用设置下载。

1.2.1 / 1.2.2 可在软件中检查更新。1.2.0 及更早版本请手动下载。手动覆盖升级前退出应用，保留 `client/.local`、`client/.models` 中原有配置、聊天副本、画像与模型。

## 数据与验证

语气只影响主动生成的回复；导出只保存当前完成结果与必要覆盖信息，不附原始聊天、API Key 或本机账号路径。总结和回复结果保存在当前进程内存，切换账号或会话会清理。API 调用沿用用户主动配置的服务，应用仍由用户确认草稿的使用。

本轮使用合成聊天和本机模型 fixture 验证，未连接真实微信账号或外部付费模型。完整审查范围与限制见 [生产审查记录](../production-review-1.3.0.md)，竞品来源与选择见 [竞品研究](../competitor-review.md)。发行包的验证和哈希见 [发行验证记录](../verification/release-1.3.0.json)。
