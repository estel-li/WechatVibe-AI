# WechatVibe 1.2.4

> 以下保留原 Electron 项目的历史发行说明。Tauri 2 构建、目录布局及更新包约定以本目录 README.md 和 MIGRATION.md 为准；这些旧下载包不用于 Tauri 2 客户端升级。

本次更新改善 API 人物画像的稳定性，新增本地并行分析、后台分析和更新提示，并优化会话列表与设置界面。

### 优化

- **API 人物画像**：简化模型返回格式，由程序统一整理分数，继续沿用本地 Laya 的判断与累计评分规则，减少格式错误和重复请求。
- **本地并行分析**：支持同时分析多路会话，默认 1 路、最多 4 路；可开启“跟随负载”，根据机器负载自动调整并行数。
- **后台分析**：新增“后台分析已添加的会话”开关，默认关闭。开启后在后台处理已添加的会话，并在侧边栏显示分析进度。
- **会话管理**：信息列表新增“全部添加”。首次进入仍由用户选择会话；使用全部添加后，仅自动加入新出现的会话，手动移除的会话不会被加回来。
- **会话过滤**：服务号和系统会话不再进入列表，普通联系人、群聊和文件传输助手继续保留。
- **更新提示**：定期静默检查新版本，发现更新时在左下角设置按钮上方显示“更新”入口，点击即可进入软件更新页面。

### 修复

- 修复 API 画像因返回的选项数量、分数加总不符而反复报格式错误的问题，移除内部补答流程，正常情况下每批调用一次模型。
- 改善长输出模型的画像兼容性，输出被截断时显示明确原因；单次画像请求等待上限调整为 240 秒，格式错误最多重试 2 次，网络异常最多重试 10 次。
- 修复部分思考模型因测试请求的输出限制过小而连接测试失败的问题。
- 修复切换本地模型、API 接入或设置标签页时窗口尺寸变化的问题，统一设置窗口尺寸，并适配小屏幕和内容滚动。

### 下载与升级

- **标准应用包**：`WechatVibe-1.2.4-windows-x64.zip`，不内置模型。解压后运行 `win-unpacked/WechatVibe.exe`，并保留完整目录。
- **源码包**：`WechatVibe-1.2.4-source.zip`，包含本版源码、测试和文档。
- **独立模型包**：继续使用 `WechatVibe-Laya-model-v1.zip`。已有模型无需重新下载；仅使用 API 时无需下载模型。
- **从 1.2.3 升级**：在“设置 → 关于 → 当前版本”检查更新。升级保留账号数据、分析结果、配置和模型。
