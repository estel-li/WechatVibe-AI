# WechatVibe Tauri 2 v1.0.0

由 [estel-li](https://github.com/estel-li) 维护，基于 [tswawa/WechatVibe](https://github.com/tswawa/WechatVibe) 上游 Electron 项目移植的 Tauri 2 独立首发版本。保留上游 Apache-2.0 许可和第三方来源声明。独立版本号从 1.0.0 开始，不代表移除上游已有功能。

## 下载与启动

| 文件 | 使用方式 |
| --- | --- |
| `WechatVibe-tauri2-1.0.0-windows-x64-setup.exe` | 安装版，运行向导安装到当前用户目录 |
| `WechatVibe-tauri2-1.0.0-windows-x64.zip` | 绿色版，解压后保留完整 `tauri2-portable` 目录，启动 `WechatVibe.exe` |

需要 Windows 10/11 x64、WebView2 Runtime 和已登录的 Windows 微信 4.x。安装器在 WebView2 缺失时提供安装引导；绿色版需要系统已有该运行时。两个包都内置 Node/Python，不含模型权重。本地模式首次使用在设置中下载 Laya 或选择已有模型；仅用 API 时无需下载模型。

## 本版本内容

- Rust + Tauri 2 + WebView2 替换 Electron 桌面宿主，保留消息情绪与意图、人物画像、群聊画像、模型设置、账号和本地缓存功能。
- 优化消息列表刷新、日期格式化、设置弹窗和键盘操作，修复剪贴板处理及后台异常退出清理。
- 关于页显示 estel-li 与 GitHub 链接；README 保留完整功能介绍、使用说明、隐私边界和上游署名。
- 应用内更新使用本仓库 Releases 和本版本独立的 Ed25519 签名。附带的更新清单、签名和校验文件由更新器使用；手动安装只需 EXE 或 ZIP。`SHA256SUMS.txt` 可核对所有发布资产。

测试覆盖业务回归、桌面宿主、更新签名与包内容，以及使用合成数据的真实 WebView2 页面验证；本次发行未连接真实微信账号或在线分析提供商。

完整说明见 [README](../../README.md)。本地模式在本机分析；启用 API 后，会将分析需要的聊天片段发送至用户配置的服务。升级时保留现有 `client/.local` 和 `client/.models`；便携版保持安装目录可写。
