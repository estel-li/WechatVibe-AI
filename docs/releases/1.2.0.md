# 知意 AI / WechatVibe AI v1.2.0

本版提供聊天界面的大模型分析快捷选择，并采用维护者提供的新 logo：绿色双对话气泡与中央四芒星，由 [estel-li](https://github.com/estel-li) 维护。

## 下载与启动

| 文件 | 使用方式 |
| --- | --- |
| `WechatVibe-tauri2-1.2.0-windows-x64-setup.exe` | 安装版，按向导安装到当前用户目录 |
| `WechatVibe-tauri2-1.2.0-windows-x64.zip` | 绿色版，解压后保留整个 `tauri2-portable` 目录，启动 `WechatVibe.exe` |

需要 Windows 10/11 x64、WebView2 Runtime 和已登录的 Windows 微信 4.x。安装器在 WebView2 缺失时提供安装引导；绿色版需要系统已有该运行时。两个包均内置 Node/Python，不含 Laya 模型权重。本地分析首次使用需下载或选择模型，使用大模型 API 时无需下载 Laya。

## 本版本内容

- **快捷选择分析模型**：聊天和人物画像页面顶部共用一个选择栏，可快速切换本地 Laya 与已保存的大语言模型，并显示当前模型名称。
- **大模型意图与画像**：意图识别、情绪标签、单聊及群聊画像复用现有 API 分析链路，使用所选模型。AI 总结与“帮我回复”继续使用独立助手配置。
- **模型列表与容量**：从“大模型设置”获取同一服务的模型列表后可快捷选择，未知上下文容量先确认再启用。
- **切换与缓存**：各模型结果独立保留，切回已有来源恢复缓存；切换失败保留已确认的来源，快捷操作不会提交未保存的配置草稿或密钥。
- **新 logo**：软件页面、Windows 多尺寸图标与 GitHub 首页使用维护者指定的原图，保留绿色背景与双气泡构图。

保留1.1.0的聊天总结、回复草稿、长聊天截断恢复、DeepSeek 1M配置与最近1天/一周/一月快捷时间选择，以及原有本地分析、会话管理和账号缓存功能。

## 升级与校验

1.0.0和1.1.0用户可在“设置 → 关于 → 当前版本”检查更新。发布页附带 Ed25519 签名更新清单、签名和校验文件；手动安装只需下载 EXE 或 ZIP，`SHA256SUMS.txt` 可核对全部发布资产。

手动覆盖升级前完全退出应用，使用完整运行包，并保留原安装的 `client/.local`（账号、配置及缓存）和 `client/.models`（已有模型）。安装到新目录不会自动迁移旧目录的账号数据；便携版目录需要可写。

此轮检查覆盖完整回归、两种包内的原生桌面与 AI 操作、实际 HTTP/Python/Node/SDK 分析链路、文件哈希及签名。聊天数据和模型服务使用本机合成 fixture，未连接真实微信账号或外部模型服务。新包不含账号数据或预置 API Key；启用 API 后，任务所需聊天片段会发送至用户配置的服务。记录见 [1.2.0 发行验证](https://github.com/estel-li/WechatVibe-AI/blob/v1.2.0/docs/verification/release-1.2.0.json)。

发行检查通过495项Node、495项Python、4项Rust测试和8个脚本套件；两个包分别通过20项AI助手与14项分析模型桌面检查，6个Windows图标尺寸均与指定logo一致。

使用说明见 [分析模型快捷选择](https://github.com/estel-li/WechatVibe-AI/blob/v1.2.0/docs/analysis-models.md) 与 [README](../../README.md)。基本功能 fork 自 [tswawa/WechatVibe v1.2.4](https://github.com/tswawa/WechatVibe/releases/tag/v1.2.4)，后续 Tauri 2 架构、AI 功能及改进由 estel-li 持续制作，保留上游 Apache-2.0 许可和第三方来源声明。
